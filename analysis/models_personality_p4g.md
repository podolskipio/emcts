# Do the models actually use a persona? (p4g persuadee simulator)

Probe of whether an LLM user simulator *responds* to persona conditioning at all, before
spending a planner run on it. A model that silently ignores the persona turns the whole
`--p4g_persona` experiment into a no-op that still completes and still reports numbers.

Generated by `scripts/report_persona_probe.py` from `scripts/probe_persona_response.py`
output. Every number below comes from those JSONs; nothing is hand-entered.

## Design

- **20 profiles**, a balanced 2×2 over the extremes of agreeableness ×
  neuroticism, taken from the real Persuasion for Good pre-task survey
  (`data/p4g_personas/full_info.csv`), restricted to the annotated 300.
- **5 fixed Persuader utterances**, one per act type. Identical across every
  profile and condition, so the persona is the only thing that varies.
- **2 samples** per (profile, act) cell →
  **200 generations per condition**,
  run with and without the persona.
- Generation goes through the production `PersuadeeChatModel` at the same sampling settings
  `build_agents` uses (`temperature=1.1`,
  `top_p=0.9`, `top_k=40`).
- Emotions from `j-hartmann/emotion-english-distilroberta-base`; embeddings from
  `minilm:sentence-transformers/all-MiniLM-L6-v2`.

**The no-persona condition is the control.** There all profiles get a byte-identical
prompt, so its cross-profile divergence is pure sampling noise. A persona is being read
only if persona divergence sits meaningfully above that floor.

## Verdict

| Model | Verdict | Divergence lift | high-N → fear+sadness |
| --- | --- | --- | --- |
| `vicuna-13b-v1.5-awq` | **narrows output rather than differentiating**, direction unconfirmed | 0.85× | +0.065 [-0.029, +0.159] |

*Divergence lift = persona divergence ÷ no-persona divergence. 1.0× means the persona
changed nothing beyond sampling noise. The directional column is the high-neuroticism
minus low-neuroticism difference in fear+sadness mass, with a bootstrap 95% CI; the
interval must clear 0 for the model to be using the persona *correctly*, not just
differently.*

### Sample generations — same utterance, opposite personas

Persuader: *"Would you be willing to donate a small part of your task payment to Save the Children today?"*

**`lowA_highN`** (agreeableness/neuroticism extreme)

> [neutral] I'm willing to hear more about the charity and what it does. I always try to stay informed and make decisions based on the information I have.  
> `→ neutral`

> [neutral] I'm not sure, I will have to think about it. Can you give me some more information about the charity and how my donation will be used?  
> `→ neutral`

> [neutral] I'm not sure, can you tell me more about the charity and how my donation would be used?  
> `→ neutral`


**`highA_lowN`** (agreeableness/neuroticism extreme)

> [neutral] I believe that donating a small part of my task payment to Save the Children is a worthy cause. However, I would like to know more about the organization, such as the percentage of my donation that would actually go towards helping the children, and their policies on transparency and accountability. I also would like to see if there are any specific projects or programs that my donation would support. Once I have that information, I can make an informed decision about whether to donate.  
> `→ neutral`

> [neutral] That sounds like a great cause, but I'm curious about the impact my donation would make. Can you tell me more about how the money is used and how it helps the children?  
> `→ surprise`

> [neutral] I understand the importance of helping vulnerable children, but I would like to know more about this charity and their impact before making any donations. Can you provide me with more information about Save the Children and their work?  
> `→ neutral`


**No persona** (same prompt every time)

> [neutral] I am open to it, I think it's a good cause. I'll donate 1 dollar.  
> `→ happiness`

> [neutral] I am willing to consider it, could you tell me more about the charity?  
> `→ happiness`

> [neutral] I understand the importance of the cause, but I need to think about it first and see if I am able to make a donation.  
> `→ neutral`


## Not yet probed

These were requested but have not been run, so no numbers for them appear above:

- `meta-llama/Llama-3.1-8B-Instruct`
- `Qwen/Qwen3-8B`

Each needs the GPU to itself — this box is a single 24 GB RTX 4090 and the SGLang
server for the model above already holds ~22 GB. To add one:

```bash
# stop the running SGLang server first, then
python -m sglang.launch_server --model-path <repo/model> --port 30000
python scripts/probe_persona_response.py --model_label <label>
python scripts/report_persona_probe.py     # rebuilds this document with all runs
```
